# Raw Data Source

This project uses the **Brazilian E-Commerce Public Dataset by Olist**.

Raw CSV files are not committed to this repository (dataset license/size
considerations). To reproduce this pipeline from scratch:

1. Download the dataset from Kaggle:
   👉 https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

2. Extract the CSVs into this folder (`data/raw/`).

3. Run the cleaning script in `python/` to generate the cleaned files
   used by the SQL and Power BI stages of this pipeline.

---

**Dataset citation:** Olist, & André Sionek. (2018). Brazilian E-Commerce
Public Dataset by Olist. Kaggle.
